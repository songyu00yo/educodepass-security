# EduCodePass 客户端安全评估

本仓库记录对 EduCodePass macOS 客户端 1.3.0 的安全评估。EduCodePass 用于东软信息学院“码途”编程练习。

[安全发现与验证边界](SECURITY-REPORT.md) · [技术细节与验证代码](SECURITY-REPORT-FULL.md) · [许可证](LICENSE)

## 主要发现

设备私钥读取是原报告评级最高的当前发现。客户端将设备私钥存入登录钥匙串。在报告记录的测试中，同一登录会话下的系统工具无需额外授权即可读取私钥。

提取的内容可解析为 P-256 私钥，并能派生对应公钥。私钥泄露可能影响设备身份校验；服务端接受哪些操作，仍取决于登录态、权限和请求校验。

其余发现涉及客户端修改、本地检测和进程间通信权限。各项测试条件、观察结果与局限见[安全报告](SECURITY-REPORT.md)。
