# EduCodePass 客户端安全评估

EduCodePass 是东软信息学院「码途」编程练习的 macOS 客户端。本仓库记录对它的安全评估。

评估对象为 1.3.0。样本 SHA-256 与测试环境见报告开头。

共记录 8 项当前版本存在的问题，另附 1 项历史问题（1.3.0 已修复）。

## 主要发现

当前版本最严重的问题是设备私钥。客户端把它存在登录钥匙串，没有设访问控制。一条命令就能读出来：

```bash
security find-generic-password -a device-key \
  -s cn.edu.neusoft.codepass.client.device_key -w
```

读出来的是 P-256 私钥，能派生对应公钥。同用户会话下的进程可以读取它，进而产生该设备的有效签名。

历史背景：1.1.7 曾把工厂私钥内嵌在二进制里，1.3.0 已修复。

其余问题按级别列出：

| 级别 | 数量 | 说明 |
|---|---|---|
| 严重 | 1 | 设备私钥可读 |
| 高危 | 2 | 二进制完整性、IPC ACL 配置不一致 |
| 中危 | 5 | 进程黑名单、DYLD 检测、截屏监考、焦点检测、环境位掩码 |

另附 1 项历史问题（工厂私钥，1.3.0 已修复）。

每个结论都标注了验证方式。静态分析的结论写明了局限，不能当作「机制不存在」的证明。
